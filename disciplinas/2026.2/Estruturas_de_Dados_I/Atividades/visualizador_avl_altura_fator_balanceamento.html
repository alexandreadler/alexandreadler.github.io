Visualizador de Árvores AVL

Insira e remova valores para acompanhar a reorganização automática da árvore.

Convenção usada nesta aula: subárvore vazia = altura −1; nó folha = altura 0. O fator de balanceamento é FB = altura(SAE) − altura(SAD).

Construir a árvore

Cada inserção ou remoção atualiza as alturas e aplica as rotações AVL necessárias. Valores repetidos não são inseridos.

Quantidade de nós: 0
Altura da árvore: −1
Convenção: folha = 0
A árvore está vazia.
Insira um valor para começar.
Nó da árvore h = altura do nó FB = fator de balanceamento

Como interpretar

Altura: h(n) = 1 + max(h(esq), h(dir)). Para uma subárvore vazia, h = −1.
Fator: FB(n) = h(esq) − h(dir).
Árvore AVL: todos os nós devem ter FB igual a −1, 0 ou +1.

Sinal do FB: positivo indica maior altura à esquerda; negativo indica maior altura à direita.

Casos de rotação:
LL → simples à direita
RR → simples à esquerda
LR → dupla: esquerda no filho, depois direita no nó
RL → dupla: direita no filho, depois esquerda no nó

Etapas da operação

  • Aguardando a primeira operação.

Visualizador didático independente. As alturas são calculadas pela quantidade de arestas, de modo que folhas têm altura 0 e árvores vazias têm altura −1.
