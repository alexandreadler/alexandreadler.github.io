ESTRUTURAS DE DADOS I

Exercício de Fixação: Árvores Binárias

Atividade prática sobre conceitos, notação textual, altura e algoritmos de travessia em árvores binárias.

1. O que caracteriza uma árvore binária de forma geral?

2. Na travessia em pré-ordem (pre-order), qual é a ordem de visitação dos nós?

3. Na travessia in-ordem (ordem simétrica), qual é a ordem de visitação?

4. Na travessia em pós-ordem (post-order), quando a raiz principal é visitada?

5. Notação Textual de Árvores Binárias

Conforme visto em aula, uma árvore não vazia pode ser descrita textualmente no formato <raiz sae sad>, onde árvores vazias são representadas por <>. Analise a árvore abaixo:

Qual alternativa representa corretamente a notação textual completa de uma árvore onde a é a raiz, b é filho esquerdo (sem filhos) e c é filho direito (sem filhos)?

6. Conceito de Altura de uma Árvore

A altura de uma árvore binária é definida na literatura como o comprimento (quantidade de arestas) do caminho mais longo que vai da raiz até uma das folhas. Com base nisso, se uma árvore possui apenas o nó raiz a (sem subárvores), qual é a sua altura?
