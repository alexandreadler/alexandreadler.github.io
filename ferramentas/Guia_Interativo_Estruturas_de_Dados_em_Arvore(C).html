💡 Conceito Fundamental: Estrutura Hierárquica e Representação em Memória

Na Ciência da Computação, uma árvore é uma estrutura de dados hierárquica não linear representada com o nó raiz no nível superior (nível 0) e os nós folha nas extremidades inferiores. Em C, cada nó é implementado como uma estrutura autorreferenciada (struct) alocada dinamicamente, composta por três campos:

info: Campo de dado que armazena a chave ou informação do nó (ex.: 'a' ou 40)
sae: Ponteiro para a Subárvore Esquerda (filho à esquerda)
sad: Ponteiro para a Subárvore Direita (filho à direita)
NULL: Ponteiro nulo que indica ausência de subárvore (árvore vazia)

Implementação em C: Definição do Nó e Alocação Dinâmica

Abaixo definimos o tipo estruturado do nó (struct no) e a função auxiliar criarNo, que realiza a alocação dinâmica na memória heap via malloc e inicializa seus ponteiros.

typedef struct no {
    char info;          // O dado guardado dentro do nó
    struct no *sae;     // Seta para Subárvore Esquerda
    struct no *sad;     // Seta para Subárvore Direita
} No;

No* criarNo(char c, No* esq, No* dir) {
    No* novo = (No*) malloc(sizeof(No)); // Reserva memória
    novo->info = c;                      // Guarda o valor
    novo->sae = esq;                     // Conecta filho esquerdo
    novo->sad = dir;                     // Conecta filho direito
    return novo;                         // Devolve o endereço
}

// Construção de baixo para cima (dos filhos para a raiz):
No* d = criarNo('d', NULL, NULL); // 1. Folha 'd' sem filhos
No* b = criarNo('b', NULL, d);    // 2. 'b' aponta para 'd'
No* e = criarNo('e', NULL, NULL); // 3. Folha 'e'
No* f = criarNo('f', NULL, NULL); // 3. Folha 'f'
No* c = criarNo('c', e, f);       // 3. 'c' liga 'e' e 'f'
No* raiz = criarNo('a', b, c);    // 4. Raiz 'a' liga tudo!
Por que começamos de baixo para cima aqui? Para conectar o pai 'a' aos filhos b e c, os filhos precisam existir primeiro na memória para terem um endereço (ex: 0x1080) para onde apontar!

🧭 O que são Percursos e o que significam as siglas R - E - D?

Percorrer (ou caminhar em) uma árvore binária consiste em visitar sistematicamente cada um de seus nós exatamente uma vez. Como a definição da estrutura é recursiva, cada nó envolve três operações fundamentais, representadas pelas siglas:

R = Raiz: Visitar/imprimir o nó atual onde você está
E = Esquerda: Explorar toda a subárvore da esquerda (sae)
D = Direita: Explorar toda a subárvore da direita (sad)
  • Pré-Ordem (R - E - D): Imprime o nó antes de descer para os filhos (Raiz primeiro, depois Esquerda, depois Direita).
  • In-Ordem (E - R - D): Vai tudo para a Esquerda, imprime a Raiz no meio, e depois vai para a Direita.
  • Pós-Ordem (E - D - R): Visita todos os filhos primeiro (Esquerda e Direita) e só imprime a Raiz por último.

🔍 Definição Formal: Árvore Binária de Busca (ABB)

            
Uma Árvore Binária de Busca é uma árvore binária cuja organização respeita a seguinte propriedade de ordenação para todo nó v:

            

                
Subárvore Esquerda (sae): Todas as chaves são estritamente menores que a chave de v

                
Subárvore Direita (sad): Todas as chaves são estritamente maiores que a chave de v

            

            
Propriedade Fundamental: A execução do percurso In-Ordem (E-R-D) sobre qualquer ABB produz, necessariamente, a sequência de chaves em ordem crescente.

Desafios Guiados (Clique para abrir as dicas)

            
            

                Desafio 1: Descobrir quais são os nós folhas (Grau 0) ▼
                

                    
O que é uma folha? É qualquer nó que não tem filhos nem na esquerda (sae == NULL) nem na direita (sad == NULL).

                    
Como testar: Carregue o Exemplo 1 acima, altere os números dentro de int valores[] = {40, 10, 60, 5, 30, 50, 70}; e clique em Executar Código para ver quais números ficam nas pontas da árvore.

                

            


            

                Desafio 2: Medir a Altura da Árvore ▼
                

                    
Regra da disciplina: Uma árvore totalmente vazia vale -1. Uma árvore com apenas 1 nó (raiz sozinha) tem altura 0. A cada andar que a árvore desce, somamos +1.

                    
Como testar: Carregue o Exemplo 2, execute e depois use o atalho + inserir 25 no terminal e clique em altura para ver se a altura aumentou.

                

            


            

                Desafio 3: Provar que o percurso In-Ordem ordena os dados ▼
                

                    
Experimento: No Exemplo 3, os números {47, 25, 77, 11, ...} estão todos embaralhados. Ao clicar em Executar Código, a função inOrdem visita sempre Esquerda → Raiz → Direita, fazendo os números saírem perfeitamente ordenados do menor para o maior.

                

            


            

                Desafio 4: Verificar se a árvore está equilibrada (Fator de Balanceamento AVL) ▼
                

                    
Definição de Fator de Balanceamento (FB): Para qualquer nó v, o fator de balanceamento é dado por FB(v) = altura(v->sae) - altura(v->sad). Na condição de balanceamento AVL, todo nó deve satisfazer FB(v) ∈ {-1, 0, +1}; valores como +2 ou -2 caracterizam desbalanceamento e exigem operações de rotação.
